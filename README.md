## ⚡ Key Highlights & Features

- **Blazing Fast Performance:** 91%+ image payload reduction via modern `.webp` compression, lazy loading, and `fetchpriority="high"`.
- **Search Engine Optimized (SEO):** Full JSON-LD structured data (`Person`, `WebSite`, `ProfessionalService`, `ItemList`), XML sitemap with image extensions, robots.txt, canonical URLs, and Open Graph / Twitter Card social previews.
- **PWA Offline Support:** Dedicated Service Worker (`sw.js`) with cache-first and stale-while-revalidate strategies for instant repeat loading.
- **Interactive Cyber Terminal (`Ctrl + \``):** Functional pseudo-UNIX shell with custom commands (`help`, `whoami`, `skills`, `projects`, `matrix`, `time`).
- **Awwwards Creative UI:**
  - Magnetic morphing cursor
  - Lenis smooth inertia scrolling
  - GSAP physics and micro-interactions
  - 3D card tilt & glare physics
  - Real-time IST clock beacon for Kerala, India (UTC+5:30)
- **Direct Dispatch Inquiries:** Fast-action forms preformatted for instant WhatsApp and email consultation.

## 🚀 Quick Start

To preview or run locally:

```bash
# Clone the repository
git clone https://github.com/abhijithmr226/my-portfolio.git

# Open directory
cd my-portfolio

# Start a local static server (using any tool of choice)
# Option A: Python
python -m http.server 3000

# Option B: Node.js (npx)
npx serve .
```

Open `http://localhost:3000` in your browser.
